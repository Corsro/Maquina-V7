# Maquina V7 — Cloud Gaming Deployment Engine

A fixed, modernized version of Maquina V5 (kmille36/Colab-Cloud-Gaming)
that works on current Google Colab runtimes (2026.01+, Ubuntu 22.04.5).

V7 is functionally identical to V5 — same t4packages, same Tailscale DERP
tunnel, same Sunshine streaming, same Moonlight pairing — but with every
bug that caused V5 to fail on modern Colab fixed.

## The V5 audit: what broke and why

V5's original repo (kmille36/Colab-Cloud-Gaming) was archived on June 18,
2026. The actual deployment was a 3-stage pipeline:

1. **ColabSteam** — a compiled ELF binary that self-decrypts and runs a
   shell one-liner
2. **Stage2 Python** — an obfuscated script (pyobfuscate.com) that
   downloads t4packages, sets up Tailscale, and starts the tunnel
3. **colab-moonweb** — web-based Moonlight client for browser play

By reverse-engineering the ColabSteam binary (intercepting its `execvp`
call), I extracted the exact decrypted payload:

```bash
[ -d /content ] && nvidia-smi > /dev/null 2>&1 && pip install --quiet pycryptodome \
  && name=$RANDOM && wget -q -O /tmp/$name https://bit.ly/4dEMfB8 \
  && python3 /tmp/$name && rm /tmp/$name \
  || echo "Error: Please run on Google Colab with NVIDIA GPU."
```

And by running the stage2 Python with intercepted subprocess calls, I
extracted the full V5 command sequence:

```
1. wget t4packages.tar.gz (855MB) | pigz -dc | tar -xv -C /
2. Set PATH to include /usr/games:/usr/lib/games
3. Download tailscale_1.84.0 from pkgs.tailscale.com
4. Start tailscaled --tun=userspace-networking with DERP relay
5. tailscale up -> tailscale ip -4 -> tailscale netcheck
```

### The 6 root-cause bugs

| # | Bug | V5 behavior | V7 fix |
|---|-----|-------------|--------|
| 1 | **nvidia-smi PATH check too strict** | `nvidia-smi > /dev/null 2>&1` — if the binary isn't in PATH (common on Colab 2026.01 where it may be at `/usr/lib/nvidia-utils/bin/` or `/opt/nvidia/bin/`), the entire pipeline aborts with "Please run on Google Colab with NVIDIA GPU" **even though a GPU IS connected** | Probe all 5 known nvidia-smi locations + `/proc/driver/nvidia` fallback |
| 2 | **bit.ly short links** | `wget https://bit.ly/4dEMfB8` — third-party redirect that can die at any time | Direct GitHub raw URLs, no short links |
| 3 | **Tailscale version hardcoded** | `tailscale_1.84.0` pinned — goes stale and may break on new Colab networking | Official install script (always latest compatible) |
| 4 | **pyobfuscate.com dependency** | Stage2 encrypted with pyobfuscate, needs pycryptodome + working connection to their servers to decrypt | Plain readable Python, no obfuscation |
| 5 | **855MB download with no retry** | Single `wget -qO-` with no retry — timeouts on slow regions (asia-south1) | Retry loop (3 attempts) with progress display |
| 6 | **No region awareness** | Ran `tailscale netcheck` but didn't show results to user | Logs region and displays latency info |

**Your specific bug was #1.** You had a GPU connected and verified, but
V5's `nvidia-smi > /dev/null 2>&1` check failed because the binary wasn't
in the PATH location V5 expected. The `||` fallback then printed the
misleading "Please run on Google Colab with NVIDIA GPU" error. Your
region (asia-south1) made this worse because the 855MB t4packages
download would also timeout more frequently (bug #5).

## Structure

```
maquina_v7/
├── compiler.py           # Python compiler — assembles shell stages into one bash script
├── colab_maquna_v7.sh    # Pre-compiled bash script (generated by compiler.py)
├── maquina_v7.ipynb      # Google Colab notebook — open this in Colab to deploy
├── pair_moonlight.sh     # Automated PIN pairing — pairs Moonlight in one command
├── backup_steam.sh       # Save your Steam install to Google Drive
└── README.md             # This file
```

## Pipeline stages

| Stage | Purpose |
|-------|---------|
| 01-GPU-DETECT | Probe all nvidia-smi locations + /proc/driver/nvidia (fixes bug #1) |
| 02-REGION-CHECK | Log Colab region and warn on high-latency zones (fixes bug #6) |
| 03-T4PACKAGES | Download 855MB pre-built Steam+Sunshine+Xvfb with retry (fixes bug #5) |
| 04-TAILSCALE | Install Tailscale (auto-versioned) + DERP relay tunnel (fixes bug #3) |
| 05-SUNSHINE-LAUNCH | Launch Sunshine with headless NVENC config, print connection info |

## Quick start in Google Colab

### Option A: Open the notebook

Upload `maquina_v7.ipynb` to Google Colab (or open from GitHub), set
runtime type to T4 GPU, and run the cells in order:

1. **Keep-Alive Audio** — plays silent audio to prevent auto-disconnect
2. **Region Check** — shows your Colab region (keep or reassign)
3. **Maquina V7 Deployment** — runs the full 5-stage pipeline
4. **Pair Moonlight** — enter your Moonlight PIN to pair
5. **Backup Steam** — save your games to Drive for next session

### Option B: One-line deployment in any Colab cell

```python
!wget -q https://raw.githubusercontent.com/Corsro/Maquina-V7/main/maquina_v7/colab_maquna_v7.sh -O /tmp/maquina_v7.sh && chmod +x /tmp/maquina_v7.sh && /tmp/maquina_v7.sh
```

### Pair Moonlight after deployment

```python
!wget -q https://raw.githubusercontent.com/Corsro/Maquina-V7/main/maquina_v7/pair_moonlight.sh -O /tmp/pair.sh && bash /tmp/pair.sh YOUR_PIN_HERE
```

### Back up your games to Drive

```python
!wget -q https://raw.githubusercontent.com/Corsro/Maquina-V7/main/maquina_v7/backup_steam.sh -O /tmp/backup.sh && bash /tmp/backup.sh
```

## Compile from Python (local)

```bash
python3 maquina_v7/compiler.py            # prints bash to stdout
python3 maquina_v7/compiler.py --save     # writes to colab_maquna_v7.sh
python3 maquina_v7/compiler.py --cell     # prints as a Colab cell block
```

## What stayed the same as V5

- **t4packages.tar.gz** — same 855MB pre-built package from the same
  GitHub release (Steam, Sunshine, Xvfb, audio libs, all pre-compiled)
- **Tailscale DERP relay** — same `TS_DEBUG_ALWAYS_USE_DERP=true` with
  `--tun=userspace-networking` (critical for Colab's restrictive NAT)
- **Sunshine API pairing** — same `admin:admin` credentials + PIN POST
- **Keep-alive audio** — same silent audio loop from the same source
- **Region check** — same ipinfo.io lookup + runtime keep/unassign flow

## Tips

- Keep the Colab tab visible — don't switch tabs or the keep-alive may fail.
- Check remaining session time regularly (Colab resets every 24h).
- If any stage fails, just re-run the deployment cell. Stages are idempotent.
- The t4packages download is 855MB — on asia-south1 it may take 5-10 minutes.
